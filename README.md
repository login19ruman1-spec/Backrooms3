# Backrooms — Paper 1.21.4

Исходный Gradle-проект для Paper 1.21.4 / Java 21. GitHub Actions собирает JAR и публикует его как artifact.

## Реализовано в этой стартовой версии
- `/br generate` — генерирует 12 (настраивается) тематических зон в существующем мире.
- `/br stop`, `/br info`, `/br level <номер>`.
- OP-only управление и ответы команд.
- Темы: классический жёлтый лабиринт, индустриальные тоннели, офисы, отель, Poolrooms, красный коридор, школа, бесконечный сад, пригород и тёмная зона.
- Комнаты и перегородки с проходами, освещение, водные участки Poolrooms.
- Золотые портальные площадки, перемещающие между уровнями.
- Случайные сундуки/бочки с припасами и записками SYSTEM/VIRUS.

## Сборка через GitHub
1. Распакуй ZIP и загрузи содержимое в новый GitHub-репозиторий.
2. Открой **Actions** и запусти `Build Backrooms plugin`.
3. Скачай artifact `Backrooms-Paper-1.21.4`, извлеки JAR в папку `plugins/` сервера.
4. Запусти сервер, укажи существующий мир в `plugins/Backrooms/config.yml`, затем перезапусти сервер.

**Важно:** генерация меняет блоки в указанном мире. Тестируй сначала на копии. Это базовая версия; NPC-клоны с реальными скинами, сложные иллюзии и сохранение инвентаря при смерти пока не реализованы. Сборка локально в этой среде не подтверждалась.
